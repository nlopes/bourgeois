= Shared artwork

`courtyard.png` is the original scene background.
`courtyard-nameplates.png` adds raised masonry and recessed stone-framed nameplates for both editions.
`traveler.png` is a four-frame transparent walking strip.
These images were generated with the built-in imagegen tool for this project.
The prompts are preserved in xref:courtyard.prompt.txt[courtyard.prompt.txt], xref:courtyard-nameplates.prompt.txt[courtyard-nameplates.prompt.txt], and xref:traveler.prompt.txt[traveler.prompt.txt].
The nameplate background uses the original courtyard as the edit target and the xref:../docs/research/mockups/adventure-concept.png[original concept] as its stonework reference.
The PNGs are kept without post-processing.
GRUB scales them at runtime.
The optional host theme builder extracts the first traveler cell and places it in transparent class icons at the two door positions.
It mirrors the Linux pose and leaves these original PNGs unchanged.

Both courtyard backgrounds are 1672 by 941 pixels.
The traveler strip is 1983 by 793 pixels with four equal logical cells.
The door centers are at source pixels 326 and 1358, about 19.5% and 81.2% of the image width.
Fancy uses these centers for its walking destinations.
Both editions show the OS names as part of the background artwork, inside the masonry.
The walking baseline is at 73% of the display height.

These project assets use the root MIT license.
The small hourglass, countdown tick, menu frames, footer, and gold ornaments are generated by `tools/theme.py`.
The fancy hourglass is drawn by the native renderer from the live countdown.

The optional host builder converts the system's DejaVu Sans Mono to an ASCII GRUB font with `grub-mkfont`.
It scales the menu, ornaments, and font for the requested display height.
`DejaVu-font-license.txt` contains the distribution's font notices and is copied beside the generated `menu.pf2`.
These font notices apply separately from the project artwork's MIT license.
